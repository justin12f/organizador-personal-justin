# Descripcion del proyecto

**Organizador Personal** es una aplicacion en desarrollo cuyo proposito es
ayudar a una persona a administrar sus tareas y notas personales en un solo
lugar.

En esta etapa el objetivo no es la programacion, sino preparar la estructura
inicial del proyecto: organizacion de carpetas, entorno virtual, dependencias,
control de versiones con Git y publicacion en GitHub.

## Proposito

- Centralizar la gestion de tareas diarias.
- Guardar notas rapidas asociadas al trabajo personal o academico.
- Servir como base para agregar, en el futuro, recordatorios y categorias.

## Alcance actual

- Estructura de carpetas y archivos base.
- Documentacion inicial en `docs/`.
- Punto de entrada simple en `src/main.py`.
